# 20mm Standard Gunpowder: Velocity and Penetration Reference

Combat reference for *Trenches, Guns and Magic*. Ballistic performance for 20mm rounds loaded with standard (non improved) smokeless propellant circa 1913 to 1914 baseline. Mild steel plate targets unless noted.

**Related:** [German-Military-Calibers.md](German-Military-Calibers.md) · [1914-Propellant-Technology.md](1914-Propellant-Technology.md) · [Weapons-vs-Armor-Reference.md](Weapons-vs-Armor-Reference.md) · [Military.md](Military.md)

---

## Muzzle Velocity

| Projectile | Mass | Velocity |
|---|---|---|
| Lead core FMJ | ~180g | 600 to 750 m/s |
| Steel core AP | ~160g | 700 to 850 m/s |

---

## Penetration

### Lead Core FMJ (~700 m/s)

| Thickness | Result |
|---|---|
| 6mm mild steel | Penetrates |
| 12mm mild steel | Penetrates, messily |
| 20mm mild steel | Borderline |
| 25mm+ | Fails |

### Steel Core AP (~800 m/s)

| Thickness | Result |
|---|---|
| 12mm | Clean penetration |
| 20mm | Penetrates |
| 30mm | Borderline |
| 40mm | Fails |
| 80mm | Fails completely |
